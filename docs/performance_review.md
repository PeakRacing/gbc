# 2026-10-12 核心提速审查与同步

基线：86195571fac4fea3301758bcc92a5a14e6960172。

- JR：先取有符号立即数再使用取指后的 PC，消除未定序读写导致的少跳一字节。六个位移覆盖正、负、零和边界。
- Timer：以 DIV 选定位下降沿数替代逐时钟循环；保持原有指令边界 reload 语义。审查补上 cycles=0 无操作保护，连不一致的 DIV 镜像也不修改。4718592 组对照涵盖全部 DIV/TAC、回绕、溢出、挂起 reload 和多种时钟增量。
- PPU：只在 dot 252–288 计算 Mode 3 精灵延长，保留每一步对动态 OAM、SCX 和 LCDC 的可见性，不引入状态缓存。
- APU：NR52 关闭仍输出零 PCM，冻结声道；声道倒计时未到期时推迟周期计算。2000000 步比较声道、IO 和 PCM 字节，不改采样率。

核心无操作系统依赖、无浮点、无新增分配，也未变更存档序列化和公开结构。
RT-Thread tick 采样、RGB565 放大、黑边处理和板级 LTO 配置不导入此仓库。

GB 马里奥大陆 14.020→31.163 FPS；GBC 马里奥豪华版 7.699→18.422 FPS。
这是整个移植工程含缩放/LTO的综合收益，不能归因为某一个核心补丁，也不是
所有 MCU 或所有游戏的稳态速度。仍不足约60 FPS，音频欠载仍存在。
10个ROM各600帧 CPU/PPU/帧缓存哈希/音频输出与白屏修复后未优化版本一致。

# 可选快速模式

`GBC_ENABLE_FAST_RUN` 默认 0；未编入时 `gbc_set_run_mode(...,
GBC_RUN_FAST)` 返回 `GBC_ERROR_UNSUPPORTED`。编入不等于启用：新实例仍为
`GBC_RUN_REFERENCE`，移植层在启动前明确选择模式。

`gbc_run_cycles(gbc, budget)` 执行完整指令并返回实际 CPU T 周期，允许最后
一条指令越过预算；零预算、无卡带、退出或重入不推进。`gbc_step` 保留单步
接口，快速模式下推进一条指令。模式只能在调用之间切换；执行中的回调拒绝
切换。跨线程访问仍需调用方互斥。快速工作区启用时一次分配，参考模式或
deinit 释放；分配失败保留原模式。CGB/ARGB8888 工作区为 50780 字节，静态
断言限制其不得超过 64 KiB，帧循环不分配。

快速路径保持 CPU、Timer、OAM/GDMA 和 serial 在每条指令后推进。PPU 只在
Mode 2 结束、Mode 3 结束及行末处理模式事件。Mode 2 结束锁存 OAM、LCDC、
滚动、窗口和调色板；Mode 3 结束绘制整行并处理 HBlank DMA。Mode 3 长度
沿用 `min(289, 252 + (SCX & 7) + sprite_count * 6)`。行内之后的寄存器写入
影响下一行，属于明确允许的图像时序近似。VRAM 在合成时读取，不增加像素
FIFO 精度。参考路径保持原行末渲染。

图块缓存保存两 bank、384 个图块的八行颜色索引，共 48 KiB；每图块一个
dirty 字节。CPU VRAM 写及 GDMA/HDMA 按行失效，调色板写仅更新颜色缓存。
完整固定八像素解码，透明和优先级仍由原渲染规则决定。

APU 寄存器读写前结算此前累积时间，音频关闭仍产生零 PCM。参考模式的
PCM 不变；快速模式的 PCM 允许采样端点差异。采样格式、样本数量、声道
控制与长度/包络/sweep 的现有时序模型保持。

ROM 区域映射、调色板缓存、图块缓存及快速调度均为派生状态，不增加状态
文件字段。reset/state load 重建；加载状态保持当前模式。中途恢复的当前
行使用恢复后的寄存器重新锁存，不能重建未保存的旧行锁存值；下一行重新
建立完整快照。旧电池 RAM、RTC 和 state 文件格式保持兼容。

验收以主机功能回归和固定板模拟 FPS 分开报告；编译或主机吞吐不代表
F1C200S 实时性能。快速模式默认完整绘制，不包含跳绘、降采样或超频。

# 可选快速模式

`GBC_ENABLE_FAST_RUN` 默认 0；未编入时 `gbc_set_run_mode(...,
GBC_RUN_FAST)` 返回 `GBC_ERROR_UNSUPPORTED`。编入不等于启用：新实例仍为
`GBC_RUN_REFERENCE`，移植层在启动前明确选择模式。

`gbc_run_cycles(gbc, budget)` 执行完整指令并返回实际 CPU T 周期，允许最后
一条指令越过预算；超过 UINT32_MAX-252 的预算截到该上限，保证返回值可表示。零预算、无卡带、退出或重入不推进。`gbc_step` 保留单步
接口，快速模式下推进一条指令。模式只能在调用之间切换；执行中的回调拒绝
切换。跨线程访问仍需调用方互斥。快速工作区启用时一次分配，参考模式或
deinit 释放；分配失败保留原模式。CGB/ARGB8888 工作区为 50840 字节，静态
断言限制其不得超过 64 KiB，帧循环不分配。

快速路径保持 CPU、Timer、OAM/GDMA 和 serial 在每条指令后推进。PPU 只在
Mode 2 结束、Mode 3 结束及行末处理模式事件。Mode 2 结束锁存 OAM、LCDC、
滚动、窗口和调色板；Mode 3 结束绘制整行并处理 HBlank DMA。Mode 3 长度
沿用 `min(289, 252 + (SCX & 7) + sprite_count * 6)`。行内之后的寄存器写入
影响下一行，属于明确允许的图像时序近似。VRAM 在合成时读取，不增加像素
FIFO 精度。参考路径保持原行末渲染。

图块缓存保存两 bank、384 个图块的八行颜色索引，共 48 KiB；每图块一个
dirty 字节。CPU VRAM 写及 GDMA/HDMA 按行失效，调色板写仅更新颜色缓存。
完整固定八像素解码，透明和优先级仍由原渲染规则决定。
Mode 2 结束时保存最多 10 个精灵的 OAM 索引，Mode 3 长度与行渲染复用
同一选择结果；DMG 的 X 优先级排序仍使用行锁存 OAM，参考模式保持原扫描。
若行内 LY 写入改变了实际渲染行号，精灵选择按锁存 OAM 重新扫描，保留
原核心的 LY 写入行为；不能复用另一行的索引列表。

HALT 在无待处理中断且无 GDMA stall 时推进到最近的 PPU、Timer、serial、
OAM DMA 或音频结算事件，并保留四 CPU 周期观察边界。通常指令仍逐条
推进 Timer/DMA/serial；不将 MMIO 延迟到整行末尾。完整驻留 ROM 的快速
指令取指直接使用已重建的 bank 映射，Boot、OAM DMA、RAM 取指和流式
ROM 保留 MMU 路径。ROM、调色板和图块内容不在此路径隐式改变。

APU 待结算时间上限为 512 个基础时钟（名义约 0.122 ms，允许完整指令越界），
每次 run 调用结束也结算；仍在每个采样点和 frame sequencer 事件分段推进。
四声道的 128/512 分段测试要求 PCM 字节、样本数及 APU 状态一致。寄存器读写
前结算此前累积时间，音频关闭仍产生零 PCM。参考模式的
PCM 不变；快速模式的 PCM 允许采样端点差异。采样格式、样本数量、声道
控制与长度/包络/sweep 的现有时序模型保持。

ROM 区域映射、调色板缓存、图块缓存及快速调度均为派生状态，不增加状态
文件字段。reset/state load 重建；加载状态保持当前模式。中途恢复的当前
行使用恢复后的寄存器重新锁存，不能重建未保存的旧行锁存值；下一行重新
建立完整快照。旧电池 RAM、RTC 和 state 文件格式保持兼容。

验收以主机功能回归和固定板模拟 FPS 分开报告；编译或主机吞吐不代表
F1C200S 实时性能。快速模式默认完整绘制，不包含跳绘、降采样或超频。

调度器对尚未到达下一个 PPU 事件的指令内联累加 dot；LCD 已关闭且状态
已归零时跳过重复归零。首次关闭、恢复、Mode/LY/STAT、HBlank DMA 与绘制
仍进入原事件处理函数。两种机型各 30,000 次随机周期、寄存器写入和派生
状态重建与原事件入口逐步比较 IO、PPU、缓存和完整帧缓存，不允许画面
或音频差异。该路径的 ARM 性能须单独板测，不能用调用数减少代替收益。

APU 批量推进在 sequencer 事件之前先结算此前的时钟，再单独处理事件
所在的最后一个时钟，保留现有 sequencer-before-oscillator 的事件边界顺序。
否则段末 sweep 的新频率会错误用于段中更早发生的振荡器计时器重载。
正负 sweep 及四声道 length/envelope/noise/phase 与逐时钟 APU 模型比较
完整状态和 PCM，修复前失败、修复后通过。参考模式代码和 DIV/APU 模型
不变，PCM 数量与格式不变；FAST 的相位/波形允许因修正这一错误而变化。
实际听感、CPU 成本和目标双人演示的欠载仍须分别验证。

FAST 每条指令只在 DMA 或串口剩余周期非零时调用原推进函数；TAC
关闭且无 TIMA 待重载时直接推进 DIV，其它定时器状态走原实现。
MMIO 边沿、IRQ、双速周期换算与参考模式保持不变。随机差分测试
覆盖零周期、DIV 回绕、TIMA 重载以及 DMA/串口完成；收益须板测确认。

FAST 编入时，CPU 的 B/C/D/E/H/L/A 字节访问通过命名成员的 offsetof
表分派，使用 unsigned char 别名访问，保持大小端成员布局。(HL) 保留
原 MMU 读写，指令周期、flags、IRQ 和存档布局不变。未编入 FAST 时
保留原 switch。全部 63 种 LD r,r 编码各 256 组数据验证完整 CPU 状态
与 (HL) 写入；进一步验证完整 ROM/PCM 回放及掌机速度后决定是否保留。
